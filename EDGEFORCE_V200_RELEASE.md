# V200 sportsbook price review

V200 adds an independently corroborated pregame price review to the Observed Sportsbook Prices panel and to `/api/live-board` and `/api/live-data/status`. The APIs expose `priceReview` under an additive sub-schema. The runtime release identity remains 119.0.0 and the existing board schema remains compatible.

The V199 baseline had zero certified sportsbook providers. The stored certification recorded 2 The Odds API credits remaining against a 25-credit reserve, zero eligible persisted prices, ESPN/DraftKings reference observations without bookmaker update times, and a FanDuel-labelled tape without verified outcome names. Only the existing Odds API credential was configured in the release secrets. There was no authorized pair of independent feeds to activate during V200.

## Price evidence

- Configured generic feeds use a fixed HTTPS origin, a documented upstream operator, and an explicit list of sportsbook brands. Two distinct configured slots, origins, upstream operators and book brands must match. This corroborates the market and its offered prices across approved sources, based on the operator assignments supplied by the administrator.
- Matching uses exact sport, league, oriented teams, scheduled instant, market, settlement rule, outcome set, USD and line. Text normalization covers whitespace, casing and Unicode composition. Provider event IDs are source-scoped, and ambiguous IDs are withheld.
- A complete current book market requires all two or three outcomes at the same source update time. Market status must be OPEN. An expired, started, missing-time, incomplete or conflicting revision cannot restore an older price. A later withdrawal for a book suppresses an older syndicated copy of that same book and market. The source update window is at most five minutes and independent source updates must be within two minutes of one another. A display row expires at the earliest contributing expiry or scheduled start.
- Approved feeds share the existing acquisition pipeline and panel cache. Requests have a time limit, forbid redirects and cap the response at 4 MiB. Sources fail independently. The API and UI disclose the number of approved feeds that responded, the number of complete book markets, matched markets, omitted results, and rejection reasons. A downstream board failure preserves acquired price evidence. The browser removes expired prices using the original update times.
- This lane produces quoted prices and source evidence. Prices never enter the model, recommendation, consensus, EV, stake or wagering paths through this lane. ESPN reference quotes and the FanDuel-labelled tape remain visible in their existing panels. Production The Odds API calls use only the quota-free sports catalog, even if the account resets to a higher balance. Cloudflare remains the deployment target and no schema migration is added.

## Connecting already-authorized feeds

Use the existing Cloudflare release workflow's optional repository secrets. Each configured slot takes `ODDS_PROVIDER_PRIMARY_URL` and optional `ODDS_PROVIDER_PRIMARY_KEY`, with corresponding SECONDARY and TERTIARY names. HTTPS endpoints may use the existing default bearer authentication. Set `ODDS_PRICE_REVIEW_APPROVALS` to single-line JSON keyed by slot ID, such as `odds-provider-primary`. The value for each slot has `origin` (the exact HTTPS origin), `operator` (the verified upstream legal operator's stable lowercase identifier), and `books` (approved lowercase brand IDs). A common upstream must use the same operator ID across all endpoints. Provider authorization and display rights must cover the bookmaker data actually supplied by that endpoint. Review-mode generic slots with missing or mismatched approvals are blocked before dispatch.

Approved JSON endpoints return an array or a `markets` array. Each row supplies `sourceEventId`, `sport`, `league`, `home`, `away`, zoned ISO `startTime`, `market` (`moneyline`, `spread`, or `total`), `period` (`FULL_GAME`), `settlementKey`, `currency` (`USD`), numeric `outcomeCount`, `venueType` (`SPORTSBOOK`), `bookmaker`, `selection`, integer American `odds`, zoned ISO `sourceTimestamp`, and `status`. For spreads, every outcome row specifies the signed home spread in `line`. Totals use the same positive threshold on both rows. Moneylines omit `line`. Selection labels for spreads and moneylines are the team names, with Draw supported in three-way moneylines. Totals use Over and Under. Publish suspended or withdrawn market revisions with the same contract identity so that prior quotes can be withheld. `sourceTimestamp` must come from the provider's market update field and must retain its value across retrievals and caches.

The next milestone is a one-league live trial with two already-authorized operators covering the same book market contracts. Verify a timestamped match, withdrawal, source outage, and expiry in production before proposing any downstream model use. Independent forecast evaluation remains a separate gate.
