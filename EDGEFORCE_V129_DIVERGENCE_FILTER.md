# EdgeForce V129 — Divergence Filter

V129 adds an opt-in movement filter to the ranked decision surface.

- All movement remains the default.
- Operators can isolate materially upgraded rows.
- Operators can isolate materially downgraded rows.
- Operators can isolate stable rows.
- Uses the V126/V127 local rank-delta analysis only.
- Adds no provider or network requests.
- Does not change qualification gates or deployment topology.
