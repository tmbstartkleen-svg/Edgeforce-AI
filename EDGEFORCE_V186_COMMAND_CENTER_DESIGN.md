# EdgeForce V186 — Command Center Design

V186 is the first post-deployment design pass on the certified V185 baseline.

## Changes
- Promotes Operator Triage into the first dashboard navigation target.
- Adds a visible certification-state badge using existing release-certification data.
- Gives the triage surface stronger visual hierarchy and six equal decision tiles.
- Improves sticky navigation depth and section targeting.
- Refines tablet and mobile layouts for triage controls and status blocks.
- Keeps all provider, ranking, qualification, and deployment behavior unchanged.

V186 adds zero provider/network requests.
