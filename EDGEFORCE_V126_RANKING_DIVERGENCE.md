# EdgeForce V126 — Ranking Divergence

V126 shows when robustness-aware ranking materially changes a market's placement versus raw simulation ranking.

- UPGRADED when priority rank improves by 3 or more places.
- DOWNGRADED when priority rank falls by 3 or more places.
- STABLE for smaller movements.
- Computed entirely from rows already loaded on the board.
- Zero additional provider/network requests.
- No changes to qualification gates or deployment topology.
