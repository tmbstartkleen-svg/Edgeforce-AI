# EdgeForce V192 — Live Game Center

V192 upgrades the live-score area into a faster in-play command surface.

## Featured live game
- Promotes a trusted live game into a larger score-and-clock view.
- Prioritizes corroborated multi-source games when available.
- Shows period, game clock, league, source confidence and synchronization state.
- Surfaces source conflicts and lagging feeds visibly instead of hiding them.

## Live pulse
- Live game count.
- Multi-source corroboration count.
- Active conflict count.
- League coverage.
- Current freshness state.

## Secondary game rail
- Compact live cards keep the remaining games visible.
- Clock hierarchy is stronger for fast scanning.
- Conflict cards receive a distinct warning treatment.

## Runtime impact
- Uses only the existing live score mesh already present in the board payload.
- Zero additional provider/API calls.
- No changes to provider cadence, simulations, odds pricing, qualification, settlement, or deployment topology.
