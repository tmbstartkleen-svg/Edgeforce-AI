# EdgeForce V188 — Sport Navigation UX

V188 improves sports-first navigation without changing model, provider, or release behavior.

## Changes
- Adds a dedicated Sport Navigator above the advanced control panel.
- Adds one-tap sport chips with live board row counts.
- Adds an active-filter summary for sport, time, market, ranking, and review queue.
- Adds one reset action for sport, time, market, simulation threshold, odds range, robustness, ranking, movement, and review filters.
- Preserves the existing Sport select as a fallback.
- Adds focus-visible states and larger mobile touch targets.

## Runtime impact
- Zero new provider/API calls.
- Uses existing board rows only.
- No simulation, ranking, qualification, settlement, or deployment topology changes.
