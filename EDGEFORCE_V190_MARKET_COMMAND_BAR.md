# EdgeForce V190 — Market Command Bar

V190 simplifies board operation without changing model logic or data traffic.

## Market-first navigation
- Adds one-tap market chips with current row counts.
- Keeps the existing market select inside advanced controls for full compatibility.
- Uses only the already-loaded board rows.

## Presets
- High Sim: SIM ranking, all robustness levels, 70% minimum simulation.
- Robust: priority ranking, ROBUST-only rows, no minimum simulation override.
- Review: priority ranking with review-queue-only enabled.
- Reset: restores the normal board defaults.

## Advanced controls
- The dense legacy control grid now lives behind an accessible Advanced Filters disclosure.
- All prior controls remain available: board period, row limit, risk, robustness, ranking, movement, review queue, sport, time, market, minimum simulation, and odds range.

## Runtime impact
- Zero new provider/API calls.
- No changes to simulations, qualifications, pricing, settlement, or production topology.
