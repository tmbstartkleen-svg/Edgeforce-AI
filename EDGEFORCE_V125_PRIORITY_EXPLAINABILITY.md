# EdgeForce V125 — Priority Explainability

V125 makes the V121 robustness-aware ranking easier to audit.

- Shows the core ingredients behind a priority score.
- Surfaces simulation probability, robustness, and dynamic confidence.
- Calls out review penalties and the strongest robustness concerns.
- Performs no additional provider or network requests.
- Does not alter qualification gates, deployment topology, or the default simulation ranking.

This is a local explainability layer for decision support.
